# How to work in this vault

This vault is the shared memory of Tidewater Labs, a two-person startup building Harbor. It is kept as an LLM wiki: people add sources and facts, agents summarize, link and keep it tidy.

- Read the index first (`vault_index`), then open only the notes you need.
- Every note has `type` and a one-line `summary`. The summary is what the index shows, so keep it specific.
- Link people, projects and concepts with wikilinks, like [[Maya Chen]] or [[Harbor]].
- Log decisions, deliveries and new facts to the daily note with `diary_add`. Skip chatter and failed attempts.
- New notes go to `inbox/` until someone files them.
- Never put secrets, passwords or personal identifiers in a note.
